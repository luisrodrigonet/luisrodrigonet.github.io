    ✒️ VSCode - Portable

    Imagine ter um ambiente de desenvolvimento completo, personalizado e portável que cabe em um pen drive. Sem rastrear arquivos de configuração espalhados pela máquina. Sem reinstalar extensões a cada novo dispositivo. Isso é possível com o Visual Studio Code em modo portável.

    Se você trabalha com Django, a escolha certa de ferramentas faz toda diferença. Um editor mal configurado pode te roubar horas de produtividade diariamente. Um editor bem estruturado te torna 30% mais rápido no desenvolvimento.

    Neste guia, você aprenderá como transformar seu VSCode em uma máquina de desenvolvimento Django profissional, completamente portável, com todas as extensões, temas e configurações sincronizadas.

    1️⃣ O que é o modo portável¶

    O modo portável do VSCode é uma configuração especial que permite ao editor viver inteiramente fora das pastas padrão do Windows (como AppData). Ao invés disso, todas as suas extensões, configurações e dados ficam em uma pasta chamada data dentro da mesma pasta do VSCode.

    🚨 Benefícios Práticos

    Benefício O Que Significa
    Portabilidade Extrema Leve seu VSCode em um pen drive e use em qualquer computador
    Zero Rastreamento Não deixa pegadas no registro do Windows ou pastas do sistema
    Sincronização Fácil Backup e migração de toda configuração em segundos
    Sem Direitos Elevados Funciona em máquinas com restrições de instalação
    Múltiplas Versões Pode ter VSCode versão 1.95 e versão 1.96 lado a lado
    Dica:

    Profissionais que trabalham em múltiplos projetos ou que frequentam diferentes clientes adoram o modo portável. Você muda de máquina sem perder nada.

    2️⃣ Instalação do VSCode em Modo Portável¶

    🔖 Download Correto (Crucial!)¶

    Aqui está o maior erro que novatos cometem: baixar o instalador errado.

    Aviso Crítico:

    Não use o instalador .exe padrão do Windows. Ele não suporta modo portável. Você PRECISA do arquivo .zip.

    Passos para fazer direito:

    1. Acesse code.visualstudio.com
    2. Clique em "Download for Windows"
    3. Procure por "Windows ZIP" — não o instalador normal
    4. Baixe a versão apropriada:
    5. Para processador Intel/AMD 64-bit: VSCode-win32-x64-1.96.X.zip (recomendado)
    6. Para processador ARM64 (ex: alguns notebooks recentes): VSCode-win32-arm64-1.96.X.zip

    🔖 Extração e Estrutura¶

    Depois que baixar o .zip:

    1. Extraia o arquivo .zip em um local permanente
    2. Exemplo: C:\DesenvolvimentoDjango ou D:\Dev\VSCode-Portable
    3. Crie uma pasta chamada data dentro da pasta extraída
    4. Pronto! Na próxima execução, VSCode reconhecerá automaticamente o modo portável
    Estrutura Final Esperada:
C:\DesenvolvimentoDjango\
├── code.exe ← duplo-clique para iniciar
├── data\    ← criar essa pasta vazia
    Validação:

    Se o VSCode abrir e criar automaticamente user-data e extensions dentro de data/, parabéns — você está em modo portável!

    🔖 Se você já tem VSCode instalado¶

    Se já usava VSCode "normalmente" na máquina, pode migrar suas configurações:

    1. Localize a pasta %APPDATA%\Code no seu Windows
    2. Copie toda essa pasta para data/ e renomeie para user-data
    3. Pronto! Suas extensões, temas e configurações virão com você

    2️⃣ Configurando o VSCode¶

    Nesta seção organizamos algumas dicas relacionadas a configuração do VSCode

    🏗️ Configuração do Idioma para Português (Brasil)¶

    Após sua primeira inicialização, o VSCode estará em inglês. Vamos mudar para português — isso leva menos de 2 minutos.

    1. Abra a Paleta de Comandos

    Pressione as teclas simultaneamente:

    Ctrl + Shift + P

    Verá uma janela ao topo do editor com um campo de entrada.

    2. Busque o Comando de Idioma

    Digite na paleta:

    display language

    Aparecerá a opção Configure Display Language — clique nela.

    3. Instale o Idioma Português (Brasil)

    Será aberta uma lista de idiomas disponíveis. Procure por:

    Portuguese (Brazil)

    Clique no botão "Install" ao lado.

    4. Reinicie o VSCode

    Após a instalação, aparecerá um botão "Restart VSCode". Clique nele.

    Quando reabrir, toda a interface estará em português: menus, paleta de comandos, extensões, tudo!

    🎯 Resultado esperado: Menu "Arquivo", "Edição", "Seleção", etc., todos em português. Se vir isso, sucesso!

    🏗️ Instalação das Extensões Essenciais para Python e Django¶

    Este é o coração da produtividade. As extensões certas farão você escrever código mais rápido e com menos erros.

    💾 Como Instalar Extensões

    Método 1 (Mais Fácil):
    1. Pressione Ctrl + Shift + X para abrir o painel de extensões
    2. Digite o nome da extensão na barra de busca
    3. Clique no botão azul "Install"
    Método 2 (Via Comando):
    1. Pressione Ctrl + Shift + P
    2. Digite Extensions: Install Extensions
    3. Digite o nome

    🚀 As 5 Extensões que você realmente precisa

    Python (Microsoft) — A Base de Tudo

    Por que: Sem essa, VSCode não entende Python. Ela é oficial, mantida pela Microsoft e traz:

    • ✅ Realce de sintaxe (as cores corretas no código)
    • ✅ Autocompletar inteligente
    • ✅ Suporte a ambientes virtuais
    • ✅ Debugger integrado (encontre bugs passo a passo)
    • ✅ Integração com testes (pytest, unittest)

    Busque por: Python Desenvolvedor: Microsoft Instalar: Clique em "Install"

    🔥 Depois dessa instalação: VSCode pedirá permissão para instalar extensões complementares (Pylance, Jupyter). Clique em "Install all" — você vai precisar delas.

    Pylance — O Superpoderoso

    Por que: Ele torna o autocompletar tão bom que parece mágica. Escreve sua variável usuario uma vez, próxima vez que digita uso, ele sugere automaticamente usuario.

    Características principais: - IntelliSense super-rápido - Detecção de erros antes de rodar o código - Documentação integrada de bibliotecas

    Busque por: Pylance Desenvolvedor: Microsoft

    Django (Official Extension)

    Por que: Extensão feita especificamente para Django. Oferece:

    • ✅ Autocompletar para sintaxe Django (templates, views, modelos)
    • ✅ Destaque de sintaxe para arquivos .html com tags Django
    • ✅ Trechos de código (snippets) para padrões comuns
    • ✅ Integração com shell Django
    • ✅ Navegação rápida entre models, views e templates

    Busque por: Django Desenvolvedor: Official Extension

    📝 Exemplo Prático: Ao digitar {% if, VSCode sugere automaticamente {% if %} ... {% endif %} — economiza digitação!

    Black Formatter — Padrão Automático

    Por que: Black é o formatador de código padrão da comunidade Python moderna. Ele automaticamente ajusta seu código para parecer profissional.

    Como funciona: - Você escreve código de qualquer jeito - Salva o arquivo (Ctrl + S) - Black reformata tudo automaticamente

    # Antes (desorganizado)
x=1+2;y={'nome':'João','idade':30}

# Depois (Black formatou)
x = 1 + 2
y = {"nome": "João", "idade": 30}

    Busque por: Black Formatter Desenvolvedor: Microsoft

    Configurar como padrão: 1. Pressione Ctrl + , (abre Configurações) 2. Busque: python formatting provider 3. Selecione: black

    Flake8 — Detector de Problemas

    Por que: Enquanto você digita, Flake8 verifica se seu código segue padrões. Avisa quando você esquece espaços, usa variáveis desnecessárias, ou infringe o guia de estilo PEP 8 do Python.

    Instale Flake8 localmente:

    Abra o terminal integrado (Ctrl + `) e execute:

    pip install flake8

    Configure em VSCode: 1. Ctrl + Shift + P → Python: Select Linter 2. Escolha flake8

    Resultado: Erros aparecem com ondulados vermelhos enquanto você digita — não precisa rodar o código para detectar!

    🏗️ Instalação do Material Icon Theme¶

    O Material Icon Theme transforma os ícones do seu VSCode em ícones modernos baseados no Material Design do Google. Parecem pequenos, mas fazem enorme diferença na velocidade de navegação.

    ⚠️ Por Que Material Icons Importa

    Imagine uma pasta de projeto Django com 50 arquivos:

    • Sem Material Icons:

      • todos com o mesmo ícone cinzento

    • Com Material Icons:

      • 📘 models.py (ícone específico)
      • 👁️ views.py (ícone de olho)
      • 🎨 templates/ (ícone especial)
      • ⚙️ settings.py (engrenagem)

    Seu olho encontra o que procura instantaneamente.

    ⚠️Vamos ao passo a passo

    Passo 1: Instalação

    1. Abra o painel de extensões

    Ctrl + Shift + X

    2. Busque por "Material Icons"

    Aparecerão várias opções. Instale a oficial:

    Material Icon Theme
Desenvolvedor: Philipp Kief

    3. Ative o tema

    Após instalar, aparecerá um popup: "Click to toggle Material Icons". Clique nele.

    Ou manualmente: - Ctrl + , → Configurações - Busque: workbench icon theme - Selecione: Material Icon Theme

    Personalização Avançada (Opcional)

    Se quiser customizar ícones específicos para pastas de seu projeto Django:

    1. Abra Ctrl + , (Configurações)
    2. Clique em "Editar em JSON" (ícone no topo direito)
    3. Procure ou crie a seção:
    "material-icon-theme.folders.associations": {
"migrations": "database",
"static": "assets",
"templates": "layout",
"tests": "testing"
}

    Agora suas pastas Django terão ícones temáticos perfeitos!

    🏗️ Configuração do Verificador Ortográfico em Português¶

    Um detalhe muitas vezes ignorado: comentários e strings com erros ortográficos prejudicam sua credibilidade profissional. Vamos ativar o verificador automático em português.

    Instalação do Code Spell Checker

    1. Instale a extensão base

    Ctrl + Shift + X

    Busque por: 

    Code Spell Checker
Desenvolvedor: Street Side Software

    Clique em "Install".

    2. Instale o dicionário português

    Você precisa de um dicionário separado para português, porque a extensão base vem apenas com inglês.

    Ctrl + Shift + X

    Busque por: 

    Brazilian Portuguese - Code Spell Checker
Desenvolvedor: Street Side Software

    Testando o Verificador
    1. Crie um novo arquivo chamado teste.py:
    # isto é um comentário com um erros ortográfico
def saudacao():
    mensagem = "Olá, mundo!"  # erros será detectado
    return mensagem
    1. Salve o arquivo

    2. Aguarde 2 segundos — aparecerandonhas onduladas (squiggly lines) em palavras com erro

    3. Passe o mouse sobre a palavra marcada

    4. Uma lâmpada aparecerá — clique nela para ver sugestões
    Adicionando palavras ao dicionário

    Às vezes, Code Spell Checker marca variáveis da sua código como erro (ex: usuario_logado pode ser marcado).

    Para adicionar palavras ao dicionário permanentemente:

    1. Clique na lâmpada de sugestão
    2. Selecione "Add to Dictionary" ou "Add to Workspace Settings"

    A palavra nunca mais será marcada como erro no seu projeto.

    💡 Dica Pro:

    • Use "Add to Workspace Settings" para erros específicos do seu projeto (nomes próprios, acrônimos customizados).

    3️⃣ Backup e Sincronização Entre Máquinas¶

    Uma das melhores partes do modo portável é a facilidade de backup.

    Backup Rápido
    1. Feche VSCode
    2. Copie a pasta inteira C:\DesenvolvimentoDjango para:
      • Um pen drive
      • OneDrive
      • Google Drive
      • Um backup externo
    Restauração

    Para usar em outra máquina:

    1. Coloque a pasta em um novo local
    2. Clique em code.exe
    3. Pronto! Todas as extensões, configurações e temas estão ali

    Nenhuma instalação, nenhuma configuração extra.

    🔒 Segurança:

    • Se usa a máquina compartilhada, VSCode portável não deixa rastreamento.

    4️⃣ Solução de Problemas Comuns¶

    VSCode não reconhece ambiente virtual

    Solução:

    1. Ctrl+Shift+P → Python: Select Interpreter
    2. Procure por ./env_django/Scripts/python.exe
    3. Selecione
    Black não está formatando

    Solução:

    pip install black

    Então:

    1. Ctrl+Shift+P→Python: Select Formatter`
    2. Escolha black
    Flake8 mostra muitos erros

    Isso é bom! Significa que está funcionando. Configure o Flake8 para ignorar certas regras:

    Crie um arquivo .flake8 na raiz do projeto:

    [flake8]
max-line-length = 88
ignore = E501, W503
    Modo portável não funciona

    Verifique:

    1. Está usando arquivo .zip e não o instalador .exe? ✓
    2. Criou uma pasta data vazia? ✓
    3. Está em um local com permissão de escrita? ✓
