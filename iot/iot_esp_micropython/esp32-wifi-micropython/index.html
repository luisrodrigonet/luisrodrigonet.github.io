    🧰 Explorando as Funcionalidades WiFi do ESP32

    Imagine um mundo onde seus projetos eletrônicos conversam entre si pela Internet, onde um simples microcontrolador controla luzes da sua casa do outro lado do mundo, onde a Internet das Coisas sai da teoria e vira realidade na sua bancada. Isso é totalmente possível com o ESP32 e MicroPython.

    O ESP32 não é apenas um microcontrolador poderoso — é uma porta de entrada para a automação e IoT. E a melhor parte? Você pode programá-lo em Python, a linguagem mais amigável do universo da programação.

    Neste artigo, você descobrirá como desbloquear o potencial WiFi do ESP32 e criar projetos que se conectam à Internet de forma simples, elegante e funcional. Se você é iniciante ou um desenvolvedor procurando dominar essas funcionalidades, este guia prático é seu mapa de tesouro.

    1️⃣ Por Que O ESP32 Com MicroPython? 🎯¶

    Antes de começarmos, você merece saber por que essa é a combinação certa.

    🔖 A Potência Do Hardware¶

    O ESP32 é fabricado pela Espressif Systems e oferece capacidades impressionantes:

    • Dual-core a 240 MHz — processamento rápido e multitarefa
    • WiFi de banda dupla (2.4GHz e 5GHz) — conectividade moderna
    • Bluetooth integrado — comunicação sem fio adicional
    • Pinos GPIO numerosos — controle de múltiplos periféricos
    • Preço acessível — tecnologia de ponta sem quebrar o banco

    🔖 A Acessibilidade Do MicroPython¶

    MicroPython é uma implementação enxuta e eficiente de Python otimizada para microcontroladores. Ao contrário do C/C++ tradicional, ele oferece:

    • Sintaxe Python familiar — você aprende uma vez, usa em qualquer lugar
    • Desenvolvimento rápido — de ideia para código em segundos
    • Curva de aprendizado suave — perfeito para iniciantes
    • Comunidade ativa — documentação, exemplos e suporte abundantes

    2️⃣ Preparação Inicial: O Que Você Precisa¶

    Antes de começar, prepare seu ambiente. A boa notícia? Não é nada complicado.

    🔖 Componentes de Hardware¶

    Componente Descrição Onde Encontrar
    ESP32 DevKit v1 Placa de desenvolvimento com 30 pinos Aliexpress, Mercado Livre
    Cabo Micro USB Para programação e alimentação Qualquer loja de eletrônica
    Computador Windows, macOS ou Linux Você já tem um :)
    Rede WiFi Para conectar e testar Sua rede doméstica

    Aviso Importante:

    Se você está usando Windows, pode precisar instalar drivers CH340 ou CP2102 (dependendo de qual versão da placa você tem). Procure "CH340 drivers" ou "CP2102 drivers" se a porta USB não for reconhecida automaticamente.

    🔖 Software Necessário¶

    1. Thonny IDE — O ambiente perfeito para MicroPython
    2. MicroPython Firmware — O sistema operacional do ESP32
    3. Python 3.7+ (opcional, mas recomendado)

    3️⃣ Configurando o Thonny IDE¶

    O Thonny IDE é nosso melhor amigo nesta jornada. É intuitivo, poderoso e foi praticamente feito para MicroPython.

    Ao abrir o Thonny pela primeira vez, ele perguntará sobre a configuração inicial. Se você não souber o que fazer, deixe as opções padrão—você configura tudo depois.

    Agora vem a parte importante: configurar o Thonny para reconhecer seu ESP32.

    Passo 1 — Acesse as preferências:

    1. Clique em Tools (Ferramentas) no menu
    2. Selecione Options (Opções)
    3. Vá para a aba Interpreter (Intérprete)

    Passo 2 — Selecione MicroPython para ESP32:

    Na dropdown ao topo, você verá "Python 3.x.x". Clique nela e procure por "MicroPython (ESP32)".

    ⬇️ Dropdown > MicroPython (ESP32) ✓

    Passo 3 — Configure a porta:

    Abaixo, você verá uma opção de "Port". Se seu ESP32 estiver conectado via USB:

    • Windows: Deve aparecer algo como "COM3" ou "COM4"
    • macOS/Linux: Deve aparecer como "/dev/ttyUSB0" ou similar

    Se nada aparecer :

    • Verifique se o cabo USB está conectado
    • Teste o cabo em outra porta USB
    • Instale drivers CH340 se necessário

    Dica de Ouro

    Se o Thonny não reconhecer a porta automaticamente, conecte seu ESP32, aguarde 2-3 segundos, e clique em "Tools > Options > Interpreter" novamente. Às vezes, é necessário reabrir a janela.

    4️⃣ Entendendo os modos WiFi do ESP32¶

    Aqui está o segredo para dominar WiFi no ESP32: existem dois modos principais, e você precisa entender a diferença.

    🔖 Modo 1: Station (STA) — O Cliente¶

    Pense em um smartphone conectado a um roteador.

    No modo Station, seu ESP32 atua como cliente e se conecta a uma rede WiFi existente (como seu roteador WiFi doméstico). Desta forma, ele ganha acesso à internet.

    Casos de uso:

    • 📊 Enviar dados de sensores para a nuvem
    • 🌍 Fazer requisições HTTP para APIs
    • 💾 Sincronizar informações com servidores
    • 🔌 Projetos IoT que precisam de internet

    Limitação:

    • Precisa de um roteador ou rede WiFi já existente.

    🔖 Modo 2: Access Point (AP) — O Servidor¶

    Pense em um roteador criando sua própria rede WiFi.

    No modo Access Point, seu ESP32 cria sua própria rede WiFi. Outros dispositivos podem se conectar a ele diretamente, como se fosse um roteador.

    Casos de uso:

    • 📱 Permitir controle via smartphone ou tablet
    • ⚙️ Configuração de credenciais WiFi
    • 🤖 Sistemas que não têm roteador próximo
    • 🔗 Redes mesh locais

    Vantagem:

    • Não depende de outra rede.

    🔖 Modo 3: Station + Access Point (Dual Mode)¶

    O melhor dos dois mundos.

    Seu ESP32 pode funcionar em ambos os modos simultaneamente. Ele se conecta a uma rede (STA) e cria sua própria rede (AP) ao mesmo tempo.

    5️⃣ Prática 1: Conectando Ao WiFi (Modo Station)¶

    Este é o prato principal. Prepare-se para fazer seu ESP32 se conectar à internet.

    🔖 O Código Básico¶

    Aqui está um exemplo simples e funcional:

    Modo Station - Exemplo 01

    import network
import time

# === CONFIGURAÇÃO ===
# Nome da sua rede
SSID = "nome _do_SSID"

# Senha da sua rede
PASSWORD = "senha_do_SSID"       

# === CRIAR INTERFACE STATION ===
sta_if = network.WLAN(network.STA_IF)

# === DESATIVAR ACCESS POINT (não vamos usar agora) ===
ap_if = network.WLAN(network.AP_IF)
ap_if.active(False)

# === FUNÇÃO PARA CONECTAR ===
def conectar_wifi():
    """Conecta o ESP32 a uma rede WiFi."""

    if sta_if.isconnected():
        print("✓ Já conectado ao WiFi!")
        return True

    print(f"Conectando a rede {SSID}...")
    """
    Desativa e reativa o modo Station
    antes de tentar a conexão
    """    
    sta_if.active(False)
    time.sleep(1)
    sta_if.active(True)

    #
    sta_if.connect(SSID, PASSWORD)

    # Aguardar conexão (máximo 10 segundos)
    timeout = time.time()
    while not sta_if.isconnected():
        if time.time() - timeout > 10:
            print("✗ Timeout! Não conseguiu conectar.")
            return False
        time.sleep(0.5)
        print(".", end="")

    print("\n✓ Conectado com sucesso!")
    print(f"IP: {sta_if.ifconfig()[0]}")
    return True

# === EXECUTAR ===
if __name__ == "__main__":
    conectar_wifi()

    🔖 Passo a Passo de Execução¶

    Passo 1 — Edite o código:

    • Substitua "SuaRedeWiFi" pelo nome (SSID) da sua rede
    • Substitua "SuaSenha123" pela senha da sua rede

    Segurança :

    Não compartilhe código com suas credenciais! No futuro, aprenda a usar variáveis de ambiente.

    Passo 2 — Salve o arquivo:

    Salve como main.py para que execute automaticamente quando o ESP32 reiniciar.

    Passo 3 — Execute o código:

    Clique no botão verde ▶ Run ou pressione F5.

    Passo 4 — Observe a mágica:

    No terminal do Thonny, você verá:

    Saída esperada - Conectado com sucesso

    🔄 Conectando a SuaRedeWiFi...
....
✓ Conectado com sucesso!
IP: 192.168.1.100

    🎉 Parabéns! Seu ESP32 está conectado à internet!

    🔖 Entendendo Cada Linha¶

    Código O Que Faz
    network.WLAN(network.STA_IF) Cria uma interface de rede para modo Station
    ap_if.active(False) Desativa o modo Access Point (AP)
    sta_if.active(True) Ativa a interface Station
    sta_if.connect(SSID, PASSWORD) Tenta conectar com as credenciais fornecidas
    sta_if.isconnected() Verifica se está conectado
    sta_if.ifconfig()[0] Obtém o endereço IP do ESP32

    6️⃣ Prática 2: Buscando dados na Internet 🎯¶

    Agora que seu ESP32 está conectado, vamos fazer ele buscar informações da internet.

    Este exemplo mostra como fazer uma requisição HTTP para uma API pública. Esta API retorna o endereço IP público utilizado para acessa-la.

    Modo Station - Exemplo 02 - Buscando dados na Internet

    import network
import urequests
import json

# === CONFIGURAÇÃO ===
SSID = "SuaRedeWiFi"
PASSWORD = "SuaSenha123"

# === CONECTAR AO WIFI ===
def conectar():
    sta_if = network.WLAN(network.STA_IF)
    sta_if.active(True)
    if not sta_if.isconnected():
        sta_if.connect(SSID, PASSWORD)
        while not sta_if.isconnected():
            pass
    print(f"✓ Conectado! IP: {sta_if.ifconfig()[0]}")

# === BUSCAR DADOS DA INTERNET ===
def buscar_ip_publico():
    """Descobre o IP público do ESP32 (como visto pela internet)."""
    try:
        response = urequests.get("https://api.ipify.org?format=json")
        dados = response.json()
        print(f"🌍 Seu IP público é: {dados['ip']}")
        response.close()
    except Exception as e:
        print(f"✗ Erro ao buscar IP: {e}")

# === EXECUTAR ===
if __name__ == "__main__":
    conectar()
    buscar_ip_publico()

    O que este código faz:

    1. Conecta ao WiFi
    2. Faz uma requisição GET para ipify.org (serviço que retorna seu IP público)
    3. Converte a resposta JSON e exibe

    Resultado esperado: 

    ✓ Conectado! IP: 192.168.1.100
🌍 Seu IP público é: 187.45.123.45

    Ideia para Expandir :

    Substitua a URL para buscar dados: - de temperatura, - notícias, - cotação de criptomoedas, - ou qualquer API pública!

    7️⃣ Prática 3: Criando Um Access Point (AP) 🏠¶

    Agora faremos o inverso: transformar seu ESP32 em um ponto de acesso WiFi.

    Este é um recurso poderoso para:

    • Configurar o ESP32 via smartphone
    • Criar uma rede local sem depender de roteador
    • Construir sistemas de controle pessoais

    Access Point - Exemplo 01

    import network
import socket

# === CONFIGURAÇÃO DO AP ===
SSID_AP = "ESP32_WiFi"          # Nome da rede que o ESP32 criará
PASSWORD_AP = "12345678"         # Senha da rede
IP_AP = "192.168.15.1"           # IP do ESP32 como roteador

# === CRIAR E CONFIGURAR O AP ===
def criar_access_point():
    """Cria uma rede WiFi usando o ESP32 como roteador."""

    ap_if = network.WLAN(network.AP_IF)
    ap_if.active(True)

    # Configurar IP estático
    ap_if.ifconfig((IP_AP, '255.255.255.0', IP_AP, '8.8.8.8'))

    # Configurar SSID e senha
    # network.AUTH_WPA_WPA2_PSK = Segurança WPA2 (recomendada)
    ap_if.config(essid=SSID_AP, authmode=network.AUTH_WPA_WPA2_PSK, password=PASSWORD_AP)

    print("✓ Access Point criado!")
    print(f"  SSID: {SSID_AP}")
    print(f"  Senha: {PASSWORD_AP}")
    print(f"  IP: {IP_AP}")
    print("\n📱 Conecte seu smartphone/tablet e acesse http://192.168.4.1 em um navegador")

# === CRIAR SERVIDOR WEB SIMPLES ===
def criar_servidor_web():
    """Inicia um servidor web básico no Access Point."""

    servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    servidor.bind(('0.0.0.0', 80))
    servidor.listen(5)

    print("🌐 Servidor web iniciado!")

    while True:
        cliente, endereco = servidor.accept()
        print(f"📥 Conexão de {endereco}")

        # Receber requisição
        requisicao = cliente.recv(1024).decode('utf-8')
        print(f"Requisição:\n{requisicao[:100]}...\n")

        # Criar página HTML
        html = """
        <html>
        <head>
            <title>ESP32 Web Server</title>
            <style>
                body { font-family: Arial; text-align: center; padding: 20px; background: #f0f0f0; }
                h1 { color: #333; }
                .status { background: #4CAF50; color: white; padding: 10px; border-radius: 5px; }
            </style>
        </head>
        <body>
            <h1>🎉 ESP32 Web Server</h1>
            <div class="status">
                <p>Seu ESP32 está online!</p>
                <p>🌐 Conectado ao Access Point</p>
            </div>
        </body>
        </html>
        """

        # Enviar resposta HTTP
        resposta = f"""HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: {len(html)}

{html}"""

        cliente.send(resposta.encode())
        cliente.close()

# === EXECUTAR ===
if __name__ == "__main__":
    criar_access_point()
    criar_servidor_web()

    🔖 Como Usar¶

    Passo 1 — Carregue o código no ESP32 e execute

    Passo 2 — Pegue seu smartphone:

    • Vá para Configurações > WiFi
    • Procure por "ESP32_WiFi"
    • Conecte com a senha "12345678"

    Passo 3 — Abra um navegador:

    • Acesse 192.168.4.1
    • Você verá a página HTML criada pelo ESP32!

    8️⃣ Prática 4: Modo Dual (Station + Access Point)¶

    Por que escolher quando pode ter os dois?

    Este exemplo mais avançado conecta o ESP32 à sua rede WiFi existente (Station) e cria um ponto de acesso próprio (Access Point) simultaneamente:

    Modo Dual - Exemplo 01

    import network
import time

# === CREDENCIAIS ===
SSID_ROUTER = "SuaRedeWiFi"
PASSWORD_ROUTER = "SuaSenha123"

SSID_AP = "ESP32_Controle"
PASSWORD_AP = "12345678"

# === CONFIGURAR STATION (conectar ao roteador) ===
def conectar_station():
    """Conecta como cliente a uma rede existente."""
    sta_if = network.WLAN(network.STA_IF)
    sta_if.active(True)

    if not sta_if.isconnected():
        print(f"🔄 Conectando a {SSID_ROUTER}...")
        sta_if.connect(SSID_ROUTER, PASSWORD_ROUTER)

        timeout = time.time()
        while not sta_if.isconnected():
            if time.time() - timeout > 15:
                print("✗ Não conseguiu conectar ao roteador")
                return False
            time.sleep(0.5)

    print(f"✓ Station conectado!")
    print(f"  IP local: {sta_if.ifconfig()[0]}")
    return True

# === CONFIGURAR ACCESS POINT (criar rede própria) ===
def criar_access_point():
    """Cria um Access Point para controle local."""
    ap_if = network.WLAN(network.AP_IF)
    ap_if.active(True)

    ap_if.ifconfig(('192.168.4.1', '255.255.255.0', '192.168.4.1', '8.8.8.8'))
    ap_if.config(essid=SSID_AP, authmode=network.AUTH_WPA_WPA2_PSK, password=PASSWORD_AP)

    print(f"✓ Access Point criado!")
    print(f"  SSID: {SSID_AP}")
    print(f"  IP AP: {ap_if.ifconfig()[0]}")

# === MODO DUAL ===
def modo_dual():
    """Ativa Station e Access Point simultaneamente."""
    print("=" * 50)
    print("  🌐 ATIVANDO MODO DUAL (STA + AP)")
    print("=" * 50)

    conectar_station()
    criar_access_point()

    print("\n✅ DUAL MODE ATIVO!")
    print("\n📡 Seu ESP32 agora é:")
    print("   ✓ Cliente (Station) — acessa internet via roteador")
    print("   ✓ Servidor (Access Point) — cria rede própria")
    print("\n🎯 Você pode:")
    print("   • Acessar via: http://192.168.4.1 (localmente)")
    print("   • Enviar dados para cloud (via Station)")

# === EXECUTAR ===
if __name__ == "__main__":
    modo_dual()

    🚀 Otimizações e Boas Práticas 🐍¶

    Agora que você domina o básico, vamos ser profissional e seguir as melhores práticas.

    Tentativa de conexão com Timeout 🐍

    Ao contrário dos exemplos anteriores (que são simples), em produção você quer estar preparado:

    Tentativa de conexão com Timeout

    import network
import time

def conectar_wifi_robusto(ssid, password, timeout=20, tentativas=3):
    """Conecta com retry automático."""

    for tentativa in range(1, tentativas + 1):
        print(f"🔄 Tentativa {tentativa}/{tentativas}")

        sta_if = network.WLAN(network.STA_IF)
        sta_if.active(True)
        sta_if.connect(ssid, password)

        inicio = time.time()
        while not sta_if.isconnected():
            if time.time() - inicio > timeout:
                print(f"✗ Timeout na tentativa {tentativa}")
                sta_if.disconnect()
                time.sleep(2)  # Esperar antes de retry
                break
            time.sleep(0.2)

        if sta_if.isconnected():
            print(f"✓ Conectado na tentativa {tentativa}!")
            return True

    print("✗ Todas as tentativas falharam")
    return False

# Uso
conectar_wifi_robusto("MinhaRede", "SenhaForte", timeout=15, tentativas=3)

    Por que isso importa :

    Em ambientes reais, WiFi nem sempre conecta na primeira tentativa. Esse retry automático evita código travado esperando conexão.

    Salvar Credenciais De Forma Segura 🐍

    Nunca coloque credenciais diretamente no código. Use um arquivo de configuração:

    config.py

    # config.py

    main.py

    # main.py
from config import WIFI_SSID, WIFI_PASSWORD

    sta_if.active(True)
    sta_if.connect(WIFI_SSID, WIFI_PASSWORD)
    while not sta_if.isconnected():
        pass
    return sta_if

    .gitignore (se usar Git) deve incluir config.py para não vazar credenciais.

    🚨 Troubleshooting: Quando As Coisas Não Funcionam 🐞¶

    Mesmo com as melhores práticas, às vezes algo não sai como esperado. Aqui estão as soluções para os problemas mais comuns:

    Problema: Port COM não aparece (Windows) 🐞

    Causa: Drivers não instalados

    Solução :

    1. Visite silabs.com (fabricante de drivers)
    2. Procure por "CP2102" ou "CH340" VCP drivers
    3. Instale para seu sistema operacional
    4. Reinicie o computador
    5. Reconecte o ESP32
    Problema: Timeout! Não conseguiu conectar 🐞

    Causas possíveis:

    • SSID/senha errados, ou WiFi não alcança

    Checklist ✅

    • Deletou caracteres especiais do SSID/senha?
    • WiFi está ligado no roteador?
    • ESP32 está próximo ao roteador (teste a distância)
    • Roteador não está filtrando MAC address?

    Debug :

    # Verificar redes visíveis
import network
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
redes = wlan.scan()

    Exemplo 2: Servidor HTTP com Controle de LED 
    # Servidor web que liga/desliga um LED via GET request
import network
import socket
from machine import Pin

led = Pin(2, Pin.OUT)  # LED no pino GPIO2

def servidor_led():
    servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    servidor.bind(('0.0.0.0', 80))
    servidor.listen(1)

    print("🌐 Servidor LED iniciado! Acesse http://192.168.4.1")

    while True:
        cliente, _ = servidor.accept()
        requisicao = cliente.recv(1024).decode()

        if 'GET /led/on' in requisicao:
            led.on()
            html = "✓ LED LIGADO"
        elif 'GET /led/off' in requisicao:
            led.off()
            html = "✗ LED DESLIGADO"
        else:
            html = "Use /led/on ou /led/off"

        resposta = f"""HTTP/1.1 200 OK
Content-Type: text/html

<h1>{html}</h1>
<a href='/led/on'>LIGAR</a> | <a href='/led/off'>DESLIGAR</a>"""

        cliente.send(resposta.encode())
        cliente.close()
