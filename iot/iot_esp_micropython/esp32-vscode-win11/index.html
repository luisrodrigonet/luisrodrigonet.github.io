    🧰 Programando o ESP32 com MicroPython no Visual Studio Code

    Imagina a cena: você acabou de comprar um ESP32, viu meia dúzia de tutoriais soltos pela Internet e, na hora de programar, fica preso entre janelas, terminais e erros enigmáticos. O código funciona em um lugar, falha em outro, e a simples tarefa de “piscar um LED” vira uma maratona de abas abertas no navegador.

    Essa frustração cresce quando você percebe que poderia estar testando ideias de IoT, protótipos de produtos ou até aulas, mas está perdendo tempo brigando com ferramentas desorganizadas. Cada pequeno ajuste exige desconectar o cabo USB, abrir outro programa, copiar e colar scripts, sem nenhum fluxo de trabalho profissional.

    A boa notícia: dá para transformar esse caos em um ambiente limpo, produtivo e moderno usando MicroPython + Visual Studio Code no Windows 11.

    Neste guia, você vai ver, passo a passo, como:

    • Gravar o firmware MicroPython no ESP32.
    • Configurar o VS Code com a extensão Pymakr.
    • Criar um projeto organizado com boot.py e main.py.
    • Subir e testar um exemplo prático no seu ESP32.

    Ao final, você terá uma base sólida para evoluir seus projetos de IoT de forma profissional.

    1️⃣ Instalando o Visual Studio Code¶

    Nesta parte, o foco é garantir que seu ambiente de edição de código esteja pronto.

    O Visual Studio Code é um editor leve, gratuito e altamente extensível. Ele oferece realce de sintaxe, IntelliSense, terminal integrado, controle de versão Git e um ecossistema enorme de extensões, incluindo ferramentas específicas para MicroPython no ESP32.

    🔖 Pré‑requisitos e materiais¶

    Nesta seção você verá tudo o que precisa ter em mãos antes de começar, para evitar interrupções no meio do processo.

    Hardware 🔖
    • 1 placa ESP32 (qualquer modelo com USB já é suficiente).
    • Cabo USB de boa qualidade (preferencialmente original ou de dados, não apenas de carga).
    Software no Windows 11 🔖
    • Visual Studio Code (VS Code) instalado.
    • Firmware MicroPython para ESP32 (arquivo .bin).
    • Python 3 instalado (para usar esptool.py, caso opte pela linha de comando).
    • Driver USB do chip da sua placa (CP2102, CH340, etc.), se o Windows não reconhecer automaticamente.
    • Extensão Pymakr no VS Code, além do Node.js, necessário para que o Pymakr funcione corretamente.

    Checklist rápido antes de continuar

    • Windows 11 atualizado
    • VS Code instalado
    • ESP32 reconhecido como porta COM
    • Firmware MicroPython baixado
    • Node.js e Pymakr instalados

    🔖 Instalando o VS Code¶

    1. Acesse o site oficial: https://code.visualstudio.com/.
    2. Baixe a versão para Windows (Build estável).
    3. Execute o instalador (VSCodeSetup-x64-...exe).
    4. Marque as opções:
      • “Adicionar ao PATH”
      • “Registrar o Code como editor de código suportado”
      • “Adicionar ação ‘Abrir com Code’ no menu do Explorador”
    5. Conclua a instalação e abra o VS Code.

    Atalho útil

    Após instalado, você pode abrir o VS Code em qualquer pasta clicando com o botão direito nela e escolhendo “Abrir com Code”. Isso ajuda muito a organizar seus projetos de ESP32.

    2️⃣ Gravando o firmware MicroPython no ESP32¶

    Agora entra o coração do processo: colocar o MicroPython dentro do ESP32. Sem isso, o microcontrolador não entende os scripts .py que você enviará.

    🔖 Baixando o firmware MicroPython¶

    1. Acesse a página oficial do MicroPython para ESP32: https://micropython.org/download/esp32/.
    2. Baixe a versão estável mais recente (arquivo .bin).

    Versão estável x versões diárias

    Para começar, use sempre a versão estável. As versões diárias (daily builds) são úteis para testar novos recursos, mas podem trazer bugs inesperados.

    🔖 Descobrindo a porta COM do ESP32¶

    1. Conecte o ESP32 ao PC via porta USB.
    2. No Windows 11, abra:
      • Win + X → Gerenciador de Dispositivos
      • Vá em Portas (COM e LPT) e anote algo como COM3, COM4 etc.

    Se nenhuma porta aparecer ou surgir um alerta de driver, você precisa instalar o driver do chip USB da sua placa (CH340, CP210x, etc.), disponível no site do fabricante.

    Sem porta COM, sem comunicação

    Se o ESP32 não aparecer como porta COM, o VS Code e o Pymakr não conseguirão conversar com a placa. Instale o driver antes de seguir.

    🔖 Instalando o firmware com esptool.py¶

    Nesta parte do guia, estamos assumindo que você já tem o Python 3 instalado no Windows.

    Abra um terminal e execute os comandos abaixo para realizar a instalação da ferramenta que será utilizada para carregar o firmware no ESP32

    1. Instale o esptool:
    🪟 Comando - Instalando o esptool 🐍
    pip install esptool
    1. Apague o conteúdo da flash do ESP32 (substitua COM3 pela sua porta):
    🪟 Comando - Apagando a flash do ESP conectado a porta COM3 🐍
    esptool.py --chip esp32 --port COM3 erase_flash
    1. Grave o firmware MicroPython:
    🪟 Comando - Carregando a flash do ESP conectado a porta COM3 🐍
    esptool.py --chip esp32 --port COM3 --baud 460800 write_flash -z 0x1000 micropython-esp32.bin

    Ao executar o comando acima substitua micropython-esp32.bin pelo o arquivo que você baixou.

    Apagar a flash é destrutivo

    O comando erase_flash apaga tudo o que estiver gravado no ESP32 (códigos anteriores, configurações, etc.). Use em placas de desenvolvimento e tenha certeza antes de executar.

    Pronto, seu ESP32 agora está rodando MicroPython.

    3️⃣ Preparando o VS Code (extensão Pymakr)¶

    Com o firmware instalado, o próximo passo é transformar o VS Code em uma IDE confortável para MicroPython, usando a extensão Pymakr.

    Nesta seção você vai instalar o Pymakr, o Node.js e conectar o VS Code ao ESP32.

    🔖 Instalando o Node.js¶

    O Pymakr depende do Node.js para funcionar corretamente, então precisamos instala-lo:

    1. Acesse https://nodejs.org/en/.
    2. Baixe a versão LTS para Windows (x64).
    3. Execute o instalador e siga o assistente (opções padrão são suficientes).

    Após a instalação, feche e reabra o VS Code.

    🔖 Instalando o Pymakr no VS Code¶

    1. Abra o VS Code.
    2. Pressione Ctrl + Shift + X para abrir a aba Extensões.
    3. Pesquise por “Pymakr”.
    4. Clique em Install.

    Ao final, um novo ícone do Pymakr aparecerá na barra lateral esquerda.

    Por que usar o Pymakr?

    O Pymakr facilita:

    • Abrir um REPL diretamente no VS Code.
    • Sincronizar pastas do projeto com o ESP32.
    • Executar rapidamente o main.py sem ficar copiando arquivos manualmente.

    4️⃣ Criando seu primeiro projeto MicroPython no VS Code¶

    Agora vamos organizar o projeto para que você tenha um fluxo semelhante ao de um desenvolvimento “de verdade”.

    Nesta seção você vai:

    • Criar uma pasta de projeto.
    • Estruturar arquivos boot.py e main.py.
    • Preparar o Pymakr para trabalharem juntos.

    🔖 Criando a pasta do projeto¶

    1. Crie uma pasta em um local fácil, por exemplo:

      • C:\Users\seu_usuario\Documents\esp32-micropython-vscode

    2. Clique com o botão direito na pasta e selecione “Abrir com Code”.

    O VS Code será aberto já com essa pasta como workspace.

    🔖 Arquivos básicos: boot.py e main.py¶

    Crie dois arquivos na raiz do projeto:

    • boot.py – executado sempre que o ESP32 é ligado ou resetado.
    • main.py – seu programa principal, rodado logo após o boot.py.[^3]

    Conteúdo mínimo sugerido:

    Arquivo: boot.py

    # boot.py
# Arquivo executado na inicialização do ESP32

import machine
import time

# Aqui você pode colocar configurações globais, como Wi-Fi no futuro.
print("Boot concluído. Iniciando main.py...")
time.sleep(0.5)

    Arquivo: main.py (exemplo de piscar o LED interno)

    # main.py
# Programa principal: piscar o LED on-board do ESP32

import machine
import time

# Em muitas placas ESP32 o LED interno está no GPIO2
led = machine.Pin(2, machine.Pin.OUT)

while True:
    led.value(1)
    time.sleep(0.5)
    led.value(0)
    time.sleep(0.5)

    LED interno pode variar

    Em algumas placas, o LED on-board não está no GPIO2. Consulte o esquema da sua placa. Se o LED não piscar, tente GPIO 2, 5 ou 13, por exemplo.

    🔖 Inicializando um projeto Pymakr¶

    1. Clique no ícone do Pymakr na barra lateral.
    2. Selecione “Create Project”.
    3. Escolha a pasta atual (onde estão boot.py e main.py).

    O Pymakr criará arquivos de configuração como pymakr.conf.

    Mantenha tudo na mesma pasta

    Sempre que possível, mantenha código, arquivos de configuração e dependências na mesma pasta raiz do projeto. Isso facilita o versionamento com Git e a replicação do ambiente em outras máquinas.

    5️⃣ Conectando e subindo código para o ESP32¶

    Chegou a hora de fazer o ciclo completo: VS Code → ESP32 → LED piscando.

    Nesta seção você vai:

    • Conectar o Pymakr ao ESP32.
    • Enviar os arquivos do projeto.
    • Acompanhar a saída via REPL integrado.

    🔖 Configurando o dispositivo no Pymakr¶

    1. Com o ESP32 conectado via USB, abra a aba do Pymakr.
    2. Clique em “Add Device”.
    3. Escolha a porta COM onde o ESP32 está (por exemplo, COM3).
    4. Dê um nome amigável, como ESP32-MicroPython.

    Depois de adicionar, o dispositivo aparecerá na lista. Selecione-o.

    🔖 Conectando ao REPL¶

    No painel do Pymakr:

    1. Clique em “Connect” (ícone de plug).
    2. A barra de status mostrará que o dispositivo está conectado.
    3. Uma aba de console (REPL) será aberta na parte inferior do VS Code.

    Você pode digitar comandos Python diretamente nesse console, por exemplo:

    import sys
sys.platform

    🔖 Subindo o projeto para o ESP32¶

    Com o Pymakr conectado:

    1. Clique em “Upload” ou “Sync Project”.
    2. O Pymakr irá enviar boot.py, main.py e demais arquivos para o ESP32.
    3. Ao final da sincronização, o ESP32 reinicia e executa boot.py e main.py.

    Se tudo estiver correto, o LED on-board deve começar a piscar.

    Testando rapidamente um comando no REPL

    Sem alterar arquivos, teste o LED diretamente:

    import machine
led = machine.Pin(2, machine.Pin.OUT)
led.value(1)  # liga o LED
led.value(0)  # desliga o LED

    6️⃣ Erros comuns e como resolver 🚨¶

    Nesta seção, o foco é antecipar os problemas mais frequentes para que você não trave no básico.

    Pymakr não conecta ao ESP32 🐞

    Sintomas: mensagens de erro como “Unable to connect” ou “Serial port not found”.

    Verificações rápidas:

    • A porta COM mudou?
      • Desconecte e reconecte o cabo USB, verifique novamente no Gerenciador de Dispositivos.
    • Outro programa está usando a mesma porta (ex.: PuTTY, Thonny)?
      • Feche todos os programas que usam serial antes de conectar o Pymakr.
    • O cabo USB é de dados?
      • Troque o cabo por um de boa qualidade.

    Reinstalar driver pode ser necessário

    Se o dispositivo aparece com ícone de alerta no Gerenciador de Dispositivos, reinstale o driver correto (CH340, CP210x, etc.) fornecido pelo fabricante da sua placa.

    Código não roda após upload 🐞

    Sintomas: nada acontece, ou o LED não pisca.

    Verifique:

    • O arquivo principal se chama main.py (com m minúsculo)?
    • Há erros de indentação (espaços x tabulações)?
    • O GPIO do LED está correto para sua placa?

    Use o REPL para testar partes do código isoladamente. Se houver exceção, ela será impressa ali.

    Erros de memória ou travamentos 🐞

    MicroPython roda em um ambiente de recursos limitados. Alguns cuidados:

    Principais Cuidados :

    • Evite listas gigantes e estruturas desnecessárias.
    • Reinicie o ESP32 com frequência durante o desenvolvimento (botão EN ou RST na placa).
    • Se estiver usando muitos módulos, considere otimizar ou usar versões “frozen” em firmware customizado (etapa avançada).
