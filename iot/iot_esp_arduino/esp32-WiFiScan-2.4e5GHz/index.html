    🤖 Guia Prático de Varredura Wi-Fi no ESP32: Como Fazer um Scan Completo com a Arduino IDE

    A varredura de redes sem fio é uma das funcionalidades fundamentais para qualquer projeto IoT que dependa de conectividade. Neste artigo, você aprenderá a realizar uma varredura (scan) exaustiva e estruturada de redes Wi-Fi utilizando o ESP32 na Arduino IDE, formatando os resultados diretamente no Monitor Serial e garantindo a compatibilidade do código com múltiplas gerações de hardware e bibliotecas.

    1️⃣ Finalidade do Código¶

    O objetivo principal deste script é demonstrar como mapear de forma eficiente todas as redes Wi-Fi ao alcance do microcontrolador ESP32.

    O fluxo de funcionamento do programa é dividido nas seguintes etapas:

    1. Inicialização: A comunicação serial é estabelecida e o Wi-Fi é configurado no Modo Estação (STA) sem efetuar uma conexão imediata.
    2. Varredura por Frequência: No loop principal, o ESP32 realiza a varredura das redes disponíveis. Através de diretivas de compilação condicional, o código verifica se o chip suporta a banda de 5GHz (além da tradicional de 2.4GHz) e alterna entre os modos de operação automático, 2.4GHz e 5GHz.
    3. Formatação dos Dados: As redes encontradas são listadas em formato de tabela no Monitor Serial, contendo informações essenciais: SSID, força do sinal (RSSI), canal (CH) e tipo de criptografia/segurança.
    4. Gerenciamento de Memória: Após a exibição dos dados, a memória utilizada para armazenar a lista de redes é liberada através da função WiFi.scanDelete(), garantindo a estabilidade operacional contínua do microcontrolador.

    2️⃣ Estudo Detalhado do Código¶

    Abaixo, analisaremos a estrutura do código dividida em suas funções principais: setup(), loop() e a função auxiliar ScanWiFi().

    ✒️ Função setup ()¶

    Este código é um template de inicialização mínima para o ESP32. O objetivo dele não é se conectar a uma rede Wi-Fi, mas sim preparar o hardware do ESP32 para atuar no "Modo Estação" (cliente Wi-Fi) e estabelecer a comunicação com o seu computador para depuração (via Monitor Serial).

    Ele "liga" o rádio Wi-Fi no modo cliente, mas aguarda instruções adicionais (que viriam no loop() ou em outra função) para de fato escanear ou conectar-se a uma rede.

    Vamos quebrar o que cada linha na função setup() está fazendo. Lembre-se, o setup() é executado apenas uma vez quando o ESP32 é ligado ou resetado.

    Codigo - Função Setup
    #include "WiFi.h"

void setup() {
  // 1. Inicializa a Comunicação Serial
  Serial.begin(115200);

  // 2. Habilita a Interface de Estação (STA)
  WiFi.STA.begin();

  // 3. Imprime uma mensagem de confirmação
  Serial.println("Setup done");
}
    Dica: WiFi.STA.begin();

    Define o modo de operação do rádio Wi-Fi como Estação (STA), ou seja, o ESP32 atuará como cliente (semelhante a um smartphone ou notebook). Quando chamada sem parâmetros (sem SSID ou senha), a função apenas liga o hardware Wi-Fi e o deixa pronto para comandos de varredura, sem tentar se conectar a nenhum roteador específico.

    ✒️ Função loop ()¶

    O código na função loop() executa uma série de varreduras (scans) de redes Wi-Fi, demonstrando como controlar especificamente quais bandas de frequência (2.4GHz ou 5GHz) o rádio do ESP32 deve procurar.

    O mais importante aqui é o uso de diretivas de compilação (#if ... #endif). Elas não são comandos que o ESP32 executa; são instruções para o compilador (na Arduino IDE) incluir ou remover partes do código antes mesmo de ele ser enviado para a placa.

    Isso torna o código "inteligente", adaptando-se automaticamente a duas condições:

    1. A versão do ESP-IDF (o sistema base do ESP32) que você está usando.
    2. O hardware específico do seu ESP32 (se ele tem ou não capacidade de Wi-Fi 5GHz).
    Código - Função Loop
        void loop() {
      Serial.println("-------------------------------------");
      Serial.println("Default wifi band mode scan:");
      Serial.println("-------------------------------------");
    #if ESP_IDF_VERSION >= ESP_IDF_VERSION_VAL(5, 4, 2)
      WiFi.setBandMode(WIFI_BAND_MODE_AUTO);
    #endif
      ScanWiFi();
    #if CONFIG_SOC_WIFI_SUPPORT_5G
      // Wait a bit before scanning again.
      delay(1000);
      Serial.println("-------------------------------------");
      Serial.println("2.4 Ghz wifi band mode scan:");
      Serial.println("-------------------------------------");
      WiFi.setBandMode(WIFI_BAND_MODE_2G_ONLY);
      ScanWiFi();
      // Wait a bit before scanning again.
      delay(1000);
      Serial.println("-------------------------------------");
      Serial.println("5 Ghz wifi band mode scan:");
      Serial.println("-------------------------------------");
      WiFi.setBandMode(WIFI_BAND_MODE_5G_ONLY);
      ScanWiFi();
    #endif
      // Wait a bit before scanning again.
      delay(10000);
    }
    Análise do código 🤖
    1. Verificação de Versão da Lib (ESP_IDF_VERSION): A constante ESP_IDF_VERSION_VAL(5, 4, 2) verifica se o núcleo do ESP32 na Arduino IDE é recente o bastante para suportar a função WiFi.setBandMode(), evitando falhas durante a compilação em ambientes legados.
    2. Verificação do Hardware (CONFIG_SOC_WIFI_SUPPORT_5G): A constante CONFIG_SOC_WIFI_SUPPORT_5G checa se o microcontrolador selecionado na IDE possui rádio Dual-Band (2.4GHz e 5GHz). Caso a placa selecionada seja um modelo padrão (apenas 2.4GHz), todo o bloco referente a 5GHz é ignorado pelo compilador, otimizando o tamanho do firmware final.
    Observações Adicionais sobre a Função loop() 🤖

    • Compatibilidade de Hardware: A maioria dos chips ESP32 clássicos e variantes populares (como ESP32-S2, ESP32-S3, ESP32-C3 e ESP32-C6) opera exclusivamente na frequência de 2.4GHz.

    • O Código Reduzido: Em placas convencionais sem suporte a 5GHz, a compilação do loop() é automaticamente reduzida para:

    Código - Versão sem suporte a 5GHz
      void loop() {
    Serial.println("-------------------------------------");
    Serial.println("Default wifi band mode scan:");
    Serial.println("-------------------------------------");
    #if ESP_IDF_VERSION >= ESP_IDF_VERSION_VAL(5, 4, 2)
      WiFi.setBandMode(WIFI_BAND_MODE_AUTO);
    #endif
    ScanWiFi();
    delay(10000);
  }

    ✒️ Função ScanWiFi()¶

    Esta função, ScanWiFi(), realiza uma varredura completa das redes Wi-Fi ao alcance do ESP32. Seu principal objetivo é descobrir e listar todas as redes disponíveis, apresentando seus detalhes em uma tabela formatada no Monitor Serial.

    A tabela inclui:

    • Um número de ordem (Nr).
    • O nome da rede (SSID), alinhado e com tamanho fixo.
    • A força do sinal (RSSI).
    • O canal em que a rede opera (CH).
    • O tipo de criptografia (segurança) da rede.

    Ao final, o código executa uma etapa de "limpeza", liberando a memória que foi usada para armazenar os resultados da varredura, o que é uma excelente prática de programação.

    Código - Função ScanWiFi
        void ScanWiFi() {
      Serial.println("Scan start");
      // WiFi.scanNetworks will return the number of networks found.
      int n = WiFi.scanNetworks();
      Serial.println("Scan done");
      if (n == 0) {
        Serial.println("no networks found");
      } else {
        Serial.print(n);
        Serial.println(" networks found");
        Serial.println("Nr | SSID                             | RSSI | CH | Encryption");
        for (int i = 0; i < n; ++i) {
          // Print SSID and RSSI for each network found
          Serial.printf("%2d", i + 1);
          Serial.print(" | ");
          Serial.printf("%-32.32s", WiFi.SSID(i).c_str());
          Serial.print(" | ");
          Serial.printf("%4ld", WiFi.RSSI(i));
          Serial.print(" | ");
          Serial.printf("%2ld", WiFi.channel(i));
          Serial.print(" | ");
          switch (WiFi.encryptionType(i)) {
            case WIFI_AUTH_OPEN:            Serial.print("open"); break;
            case WIFI_AUTH_WEP:             Serial.print("WEP"); break;
            case WIFI_AUTH_WPA_PSK:         Serial.print("WPA"); break;
            case WIFI_AUTH_WPA2_PSK:        Serial.print("WPA2"); break;
            case WIFI_AUTH_WPA_WPA2_PSK:    Serial.print("WPA+WPA2"); break;
            case WIFI_AUTH_WPA2_ENTERPRISE: Serial.print("WPA2-EAP"); break;
            case WIFI_AUTH_WPA3_PSK:        Serial.print("WPA3"); break;
            case WIFI_AUTH_WPA2_WPA3_PSK:   Serial.print("WPA2+WPA3"); break;
            case WIFI_AUTH_WAPI_PSK:        Serial.print("WAPI"); break;
            default:                        Serial.print("unknown");
          }
          Serial.println();
          delay(10);
        }
      }

      // Delete the scan result to free memory for code below.
      WiFi.scanDelete();
      Serial.println("-------------------------------------");
    }
    Análise dos Elementos da Varredura
    • WiFi.scanNetworks(): Função síncrona que suspende a execução até que o rádio finalize a escuta de todos os canais. O retorno é o número total de redes identificadas.
    • **Formatadores com Serial.printf()**:
    • %-32.32s: Garante que o SSID ocupe exatamente 32 colunas, alinhado à esquerda, cortando nomes mais longos para preservar a estrutura gráfica da tabela.
    • %4ld: Garante espaço suficiente para exibir o sinal do RSSI (que é um valor numérico negativo).
    • WiFi.scanDelete(): Função essencial de gerenciamento de recursos. Ela remove os dados da varredura atual alocados na memória RAM, evitando vazamento de memória (memory leaks) ao longo de execuções sucessivas.

    3️⃣ Observações Adicionais¶

    1. Entendendo o Indicador de Sinal (RSSI):

      • O RSSI (Received Signal Strength Indicator) é mensurado em decibéis-miliwatts (dBm), sendo representado por um valor negativo. Quanto mais próximo de 0, melhor é a qualidade da recepção:
        • -30 dBm: Sinal excelente (dispositivo muito próximo ao roteador).
        • -67 dBm: Sinal bom (suficiente para streaming e transferências contínuas).
        • -80 dBm: Sinal fraco (sujeito à perda de pacotes e latência elevada).
        • -90 dBm: Sinal limite (risco iminente de desconexão).

    2. Varredura Síncrona vs. Assíncrona:

      • Neste exemplo, o método WiFi.scanNetworks() opera de forma síncrona (bloqueante). Caso seu projeto necessite executar tarefas paralelas enquanto escaneia (como atualizar um display ou ler sensores), é possível utilizar a versão assíncrona: WiFi.scanNetworks(true).
