    📜 Configuração e Uso de Code Blocks em Material for MkDocs¶

    🔖 Por que Code Blocks Importam na Documentação¶

    Imagine um desenvolvedor chegando na sua documentação sem nenhuma ferramenta visual para entender como seu código funciona. Frustrante, não é? Code blocks não são apenas blocos de texto — são janelas interativas que transformam exemplos em lições práticas. No Material for MkDocs, esses blocos ganham superpoderes: destacam sintaxe, mostram números de linha, permitem cópia com um clique e até adicionam anotações explicativas.

    Neste guia completo, você aprenderá a dominar todos os recursos de code blocks disponíveis no Material for MkDocs, desde a configuração inicial até técnicas avançadas que farão sua documentação brilhar.

    1️⃣ Configuração Inicial — O Alicerce¶

    A maioria dos desenvolvedores pula a configuração e se vê frustrada quando o code blocks não destaca a sintaxe corretamente.

    No Material for MkDocs, você precisará ativar as extensões Markdown específicas no arquivo mkdocs.yml.

    📝 Passo 1: Configure as Extensões Essenciais¶

    Abra seu mkdocs.yml e adicione a seguinte configuração:

    mkdocs.yml
    markdown_extensions:
  - pymdownx.highlight:
      anchor_linenums: true
      line_spans: __span
      pygments_lang_class: true
  - pymdownx.inlinehilite
  - pymdownx.snippets
  - pymdownx.superfences

    O que cada extensão faz?

    • pymdownx.highlight: O motor principal para destaque de sintaxe com Pygments
    • pymdownx.inlinehilite: Permite destaque em código inline (dentro de parágrafos)
    • pymdownx.snippets: Importa código de arquivos externos
    • pymdownx.superfences: Oferece sintaxe avançada para code blocks

    📝 Passo 2: Ative Recursos Globais (Opcional, mas Recomendado)¶

    Para melhorar a experiência do usuário, ative esses recursos no arquivo mkdocs.yml:

    mkdocs.yml
    theme:
  features:
    - content.code.copy      # Botão para copiar código
    - content.code.select    # Seletor de linhas
    - content.code.annotate  # Anotações no código

    Parabéns!

    Você configurou o Material for MkDocs para oferecer uma experiência moderna de code blocks.

    Agora, vamos ao que realmente importa: como usá-los.

    2️⃣ Sintaxe Básica — Estrutura Fundamental¶

    📝 Criando um Code Block Simples¶

    A forma mais simples de criar um code block é usar três backticks (acentos graves) e especificar a linguagem:

    🏗️ Exemplo:

    Código :

        ```python
    def hello_world():
        print("Olá, Mundo!")
    ```

    🚀 Resultado esperado

    def hello_world():
    print("Olá, Mundo!")

    Atenção

    O identificador da linguagem deve estar imediatamente após os backticks de abertura, sem espaços.

    Exemplos válidos: python, javascript, yaml, bash.

    📝 Linguagens Suportadas¶

    Material for MkDocs suporta 190+ linguagens através do Pygments. Aqui estão as mais comuns:

    Linguagem Identificador

    JavaScript javascript / js
    TypeScript typescript / ts

    Dica Profissional

    Visite Pygments Languages para encontrar o identificador exato de qualquer linguagem que você necessite.

    3️⃣ Recursos Essenciais¶

    📝 Adicionando Títulos e Contexto¶

    Um code block sem contexto é como uma receita sem ingredientes. Adicione um título para indicar o nome do arquivo ou o propósito:

    🏗️ Exemplo:

    Código :

        ```python title="app.py"
    @app.route('/api/users')
    def get_users():
        return jsonify(users_list)
    ```

    🚀 Resultado esperado

    app.py
    @app.route('/api/users')
def get_users():
    return jsonify(users_list)

    📝 Numeração de Linhas¶

    Números de linha ajudam a referenciar partes específicas do código. Use linenums="<número_inicial>":

    🏗️ Exemplo:

    Código :

        ```python linenums="1" title="exemplo.py"
    def fibonacci(n):
        if n <= 1:
            return n
        return fibonacci(n-1) + fibonacci(n-2)

    print(fibonacci(10))
    ```

    🚀 Resultado esperado

    exemplo.py
    def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))

    Caso de Uso Real

    Comece a numeração de linhas de um número diferente ao dividir um código grande em partes.

    Exemplo: linenums="15" para continuar de onde parou.

    📝 Destacando Linhas Importantes¶

    Chame atenção para as linhas que importam usando hl_lines:

    🏗️ Exemplo:

    Código :

        ```python linenums="1" hl_lines="2 3" title="config.py"
    DATABASE_URL = "postgresql://user:pass@localhost/db"
    DEBUG = True
    SECRET_KEY = "sua-chave-secreta-aqui"
    ALLOWED_HOSTS = ["localhost", "127.0.0.1"]
    ```

    🚀 Resultado esperado

    config.py
    DATABASE_URL = "postgresql://user:pass@localhost/db"
DEBUG = True
SECRET_KEY = "sua-chave-secreta-aqui"
ALLOWED_HOSTS = ["localhost", "127.0.0.1"]

    Segurança

    Nunca publique credenciais reais em sua documentação!

    O exemplo acima é apenas para fins didáticos.

    Você também pode destacar intervalos de linhas:

    DATABASE_URL = "postgresql://user:pass@localhost/db"
DEBUG = True
SECRET_KEY = "sua-chave-secreta-aqui"
ALLOWED_HOSTS = ["localhost", "127.0.0.1"]

    📝 Botão de Cópia Inteligente¶

    Se você ativou content.code.copy, aparecerá automaticamente um botão no canto superior direito. Para desativar para um bloco específico, podemos utilizar { .yaml .no-copy }

    🏗️ Exemplo:

    Código :

        ```` { .yaml .no-copy }
    # Não é recomendado copiar este bloco
    sensitive_config: xxxxx
    ````

    🚀 Resultado esperado

    # Não é recomendado copiar este bloco
sensitive_config: xxxxx

    4️⃣ Anotações em Código — O Diferencial¶

    📝 O Poder das Anotações¶

    Anotações transformam código em aulas interativas. Cada número no código ativa uma tooltip com explicações. Veja como:

    🏗️ Exemplo:

    Código :

        ```python title="main.py" hl_lines="2"
    def calcular_desconto(preco): # (1)!
        return preco * 0.9 # (2)!
    ```

    1. Função que aplica desconto de 10% ao preço
    2. Multiplica por 0.9 para obter 90% do valor original

    🚀 Resultado esperado

    main.py
    def calcular_desconto(preco): # (1)!
    return preco * 0.9 # (2)!
    1. Função que aplica desconto de 10% ao preço
    2. Multiplica por 0.9 para obter 90% do valor original

    Sintaxe de Anotação

    Use # (número)! para Python, // (número)! para JavaScript, <!-- (número)! --> para HTML, etc.

    O número pode ser qualquer dígito de 1 a 9.

    📝 Anotações Avançadas em JSON¶

    Para linguagens como JSON onde comentários não existem, configure seletores customizados:

    mkdocs.yml
    extra:
  annotate:
    json: [.s2]  # Permite anotações em strings

    Depois use assim:

    {
"usuario": "João Silva (1)",
"email": "joao@example.com (2)"
}
    1. Nome do usuário no sistema
    2. Email para notificações

    5️⃣ Código Inline — Destaque em Parágrafos¶

    Quando Usar Código Inline¶

    Ao mencionar funções, variáveis ou comandos no meio de um parágrafo, use a sintaxe de código inline com destaque. Isso também é chamado de InlineHilite.

    Sem destaque: Use a função range() para gerar sequências de números.

    Com destaque: Use a função range() para gerar sequências de números.

    Sintaxe

    Prefixe com #! seguido da linguagem: #!python, #!javascript, #!yaml, etc.

    Exemplos práticos:

    • Configure seu servidor com docker-compose up
    • A variável document.querySelector() seleciona elementos do DOM
    • Use for i in range(10): para loops

    6️⃣ Importando Código de Arquivos Externos¶

    📝 Por que Importar de Arquivos?¶

    Manter código sincronizado com arquivos reais evita exemplos desatualizados. Use a extensão Snippets para isso.

    📝 Sintaxe de Importação¶

    Código :

        ``` title="config.py"
    -- 8<-- "src/config.py"
    ```

    O caminho é relativo à pasta docs/.

    📝 Importando Partes Específicas¶

    Você pode importar apenas linhas específicas usando marcadores:

    Arquivo original (src/main.py):

    Código :

        # -- 8<-- [start: setup]
    def configurar_database():
        return DatabaseConnection()
    # -- 8<-- [end: setup]

    # -- 8<-- [start: query]
    def consultar_usuarios():
        return db.query("SELECT * FROM users")
    # -- 8<-- [end: query]

    Na documentação:

    Código :

        ``` python title="main.py"
    -- 8<-- "src/main.py:setup"
    ```

    Benefício Real

    Seus exemplos nunca ficarão desatualizados porque são importados dos arquivos reais do projeto.

    7️⃣: Diferenças de Código (Diff Highlighting)¶

    📝 Mostrando Mudanças no Código¶

    Para mostrar o que mudou, use a linguagem diff:

      def usuario_info(id):
-     return db.query(id)
+     return db.query_with_cache(id)

  # A nova função usa cache para melhor performance

    🏗️ Sintaxe:

    • Linhas com - mostram o que foi removido (vermelho)
    • Linhas com + mostram o que foi adicionado (verde)
    • Linhas sem prefixo são contexto (cinza)

    Caso de Uso

    Use diff ao documentar breaking changes, migrações ou melhorias de performance.

    8️⃣ Configurações Avançadas¶

    📝 Controlando o Comportamento por Bloco¶

    Você pode ativar/desativar recursos para código blocks específicos sem afetas os globais:

    Desativar seleção de linhas para um bloco:

    Código :

        ```` { .python .no-select }
    # Código importante que não deve ser copiado parcialmente
    main_algorithm()
    ````

    Ativar anotações apenas neste bloco:

    Código :

        ```` { .javascript .annotate }
    const valor = 42; // (1)!
    ````

    1. Constante com resposta universal

    Combinações Válidas

    • .copy / .no-copy
    • .select / .no-select
    • .annotate (para ativar se global estiver desativado)

    9️⃣ Personalização de Cores e Estilos¶

    📝 Ajustando o Tema de Sintaxe¶

    Material for MkDocs oferece variáveis CSS para customizar cores. Crie um arquivo docs/css/extra.css:

    docs/css/extra.css

    :root {
--md-code-bg-color: #1e1e1e;           /* Fundo escuro */
--md-code-fg-color: #e0e0e0;           /* Texto claro */
--md-code-hl-color: rgba(255, 235, 59, 0.3); /* Destaque */
--md-code-hl-string-color: #ce9178;    /* Strings */
--md-code-hl-keyword-color: #569cd6;   /* Keywords */
--md-code-hl-comment-color: #6a9955;   /* Comentários */
}

    Depois inclua no mkdocs.yml:

    mkdocs.yml

    extra_css:
- css/extra.css

    Paleta de Cores Recomendada

    Para garantir acessibilidade, mantenha um alto contraste visual entre o texto e o fundo. Isso facilita a leitura para pessoas com deficiências visuais.

    Ferramentas como Contrast Checker ajudam.

    🔟 Exemplos Práticos Completos¶

    🏗️ Exemplo 1: Documentando uma API REST¶

    api/users.py
    from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/api/users/<int:user_id>', methods=['GET'])  # (1)!
def get_user(user_id):
    user = db.get_user(user_id)
    return jsonify(user.to_dict())  # (2)!
    1. Rota que aceita um ID como parâmetro
    2. Retorna dados do usuário em formato JSON

    Teste Localmente

    curl http://localhost:5000/api/users/1

    #️⃣ Troubleshooting e Boas Práticas¶

    1. Syntax Highlighting não Funciona¶

    🎯 Solução: Verifique se:

    1. A extensão pymdownx.highlight está no mkdocs.yml
    2. Pygments está instalado: pip install pygments
    3. O identificador de linguagem é válido

    2. Anotações não Aparecem¶

    🎯 Solução: Verifique se:

    1. content.code.annotate está em theme.features
    2. Você usou # (número)! com a exclamação
    3. O número não tem espaços: (1)! não ( 1 )!

    📣 Boas Práticas¶

    Checklist de Qualidade

    • ✅ Sempre adicione títulos aos code blocks
    • ✅ Use números de linha em blocos > 10 linhas
    • ✅ Destaque as linhas mais importantes com hl_lines
    • ✅ Adicione anotações para lógica complexa
    • ✅ Teste todos os exemplos antes de publicar
    • ✅ Mantenha código atualizado (importe de arquivos quando possível)
    • ✅ Use mais de um exemplo para conceitos diferentes

    🛣️ Conclusão: Código Blocks Memoráveis¶

    Os Code blocks não são meras decorações em documentação — são ferramentas de ensino que podem transformar como desenvolvedores entendem seu projeto.

    Aplique esses conhecimentos na sua documentação. Comece pequeno, teste diferentes recursos e veja qual estilo funciona melhor para seu público.

    Combine code blocks com outros recursos do Material for MkDocs como abas, modais e diagramas. O limite é sua criatividade.
