    Domine a Formatação no Material for Mkdocs

    🎯 Introdução¶

    Você sabe o incômodo de criar documentação que parece genérica e sem vida? Aquele texto cinzento que ninguém lê porque é monótono demais? A verdade é que 80% dos leitores online não leem de verdade — eles escaneiam.

    Isso significa que se sua documentação não for bem formatada e visualmente organizada, suas palavras podem ser ouro puro, mas ninguém vai extrair esse valor.

    Aqui está a solução: Material for Mkdocs oferece um arsenal completo de ferramentas de formatação que transformam texto plano em uma experiência visualmente rica e profissional.

    Neste artigo, você descobrirá:

    • Formatação básica de texto: negrito, itálico e combinações poderosas
    • Estilos avançados: destaque, tachado, sublinhado e efeitos especiais
    • Formatação de código: desde trechos inline até blocos completos com sintaxe colorida
    • Recursos profissionais: sub e sobrescritos, teclas do teclado e mudanças rastreadas
    • Configuração prática: exatamente como ativar cada recurso no seu projeto

    🎨 Fundamentos: Formatação Básica de Texto¶

    Negrito, Itálico e Ênfase

    A formatação básica é o alicerce de toda boa documentação. No Markdown, você tem três ferramentas simples mas poderosas.

    🏗️ Sintaxe Markdown:

    Este texto está em **negrito** ou __negrito__.
Este texto está em *itálico* ou _itálico_.
Este texto está em ***negrito itálico*** ou ___negrito itálico___.

    🚀 Resultado esperado

    • Este texto está em negrito ou negrito
    • Este texto está em itálico ou itálico
    • Este texto está em negrito itálico ou negrito itálico

    Dica de Profissional

    1. Sempre que você quiser destacar um conceito-chave em um parágrafo, use negrito.
    2. Para enfatizar a importância emocional de algo, use itálico.
    3. E quando algo é realmente crítico, combine os dois: ação urgente.

    ✨ Formatação Avançada: Destaque e Efeitos Especiais¶

    Para acessar esses poderosos recursos, você precisa primeiro ativar as extensões Markdown corretas. Esta é uma etapa crucial.

    🔖 Configuração Necessária¶

    Abra seu arquivo mkdocs.yml e adicione as seguintes extensões:

    markdown_extensions:
  - pymdownx.critic
  - pymdownx.caret
  - pymdownx.keys
  - pymdownx.mark
  - pymdownx.tilde

    Importante

    • Sem essa configuração, os exemplos que você verá a seguir não funcionarão na sua documentação.
    • Verifique se todas as cinco extensões estão presentes no seu arquivo de configuração.

    🔖 Destacar Texto¶

    O destaque (marca amarela, como quando você usa marca-texto no papel) é perfeito para chamar atenção a informações críticas.

    Sintaxe:

    Este é ==texto destacado== em sua documentação.

    🚀 Resultado esperado

    Este é texto destacado em sua documentação.

    Caso de Uso Prático

    Quando você está escrevendo sobre migração de versões, destaque as partes obrigatórias:

    "Para a v2.0, você precisa remover todas as dependências antigas. Isso é obrigatório."

    🔖 Tachado: Mostrar o Que Foi Removido¶

    Às vezes você precisa indicar que algo foi descontinuado ou não é mais válido. O tachado faz isso de forma elegante.

    Sintaxe:

    Este código ~~não funciona mais~~ foi descontinuado.

    🚀 Resultado esperado

    Este código não funciona mais foi descontinuado.

    🔖 Sublinhado: Inserção de Conteúdo¶

    Use sublinhado para mostrar adições ou conteúdo novo.

    Sintaxe:

    Para a nova versão, ^^use este método^^.

    🚀 Resultado esperado

    Para a nova versão, use este método.

    📐 Sobrescritos e Subscritos: Fórmulas Científicas e Técnicas¶

    Quando você está documentando fórmulas, notação química ou expressões matemáticas, esses recursos são indispensáveis.

    Sintaxe:

    - A molécula de água é H~2~O
- A equação de Einstein é E=mc^2^

    🚀 Resultado esperado

    • A molécula de água é H2O
    • A equação de Einstein é E=mc2

    Quando Usar

    Use subscritos para:

    • Fórmulas químicas (H₂SO₄, CO₂)
    • Variáveis numeradas (x₁, x₂, x₃)

    Use sobrescritos para:

    • Expoentes e potências (x², m³)
    • Notas de rodapé (nota¹)

    🖱️ Atalhando com Teclas do Teclado¶

    Quando você está explicando atalhos de teclado ou navegação, representar as teclas corretamente melhora drasticamente a compreensão.

    Sintaxe:

    Pressione ++ctrl+alt+del++ para abrir o gerenciador de tarefas.
Em macOS, use ++cmd+space++ para abrir o Spotlight.

    🚀 Resultado esperado

    • Pressione Ctrl+Alt+Del para abrir o gerenciador de tarefas
    • Em macOS, use Cmd+Space para abrir o Spotlight

    Combinações Úteis

    Combinação Uso
    Ctrl+C Copiar
    Ctrl+V Colar
    Ctrl+Z Desfazer
    Cmd+Shift+S Captura de tela (macOS)

    💻 Formatação de Código: Do Simples ao Profissional¶

    🔖 Código Inline (Trechos Pequenos)¶

    Quando você menciona código dentro de um parágrafo, envolva com acentos graves simples.

    Sintaxe:

    Para instalar, execute `pip install mkdocs`.
A variável `config_file` armazena o caminho da configuração.

    🚀 Resultado esperado

    • Para instalar, execute pip install mkdocs
    • A variável config_file armazena o caminho da configuração

    🔖 Blocos de Código com Destaque de Sintaxe¶

    Para blocos maiores de código, use cercas com três acentos graves e especifique a linguagem.

    Sintaxe:

    ```python
def saudacao(nome):
    return f"Olá, {nome}!"

print(saudacao("Maria"))
```

    🚀 Resultado esperado

    def saudacao(nome):
    return f"Olá, {nome}!"

print(saudacao("Maria"))
    Linguagens Suportadas

    Material for Mkdocs suporta destaque de sintaxe para:

    1. Python – python, py.
    2. JavaScript – javascript, js.
    3. TypeScript – typescript, ts.
    4. HTML – html.
    5. CSS – css.
    6. JSON – json.
    7. YAML – yaml, yml.
    8. Bash / Shell – bash, sh, shell.
    9. Markdown – markdown, md.
    10. SQL – sql.
    11. Java – java.
    12. C – c.
    13. C++ – cpp, c++.
    14. C# – csharp, cs.
    15. PHP – php.
    16. Go – go.
    17. Ruby – ruby, rb.
    18. Rust – rust.
    19. Kotlin – geralmente suportada via Pygments/Highlight como kotlin.
    20. Swift – também disponível em conjuntos modernos de lexers como swift.

    🔖 Blocos de Código com Título e Números de Linha¶

    Quando você quer que seus exemplos sejam ainda mais profissionais, adicione títulos e numeração.

    Sintaxe:

    ```python title="exemplo_titulo.py" linenums="1"
def calcula_fibonacci(n):
    if n <= 1:
        return n
    return calcula_fibonacci(n-1) + calcula_fibonacci(n-2)

print(calcula_fibonacci(10))
```

    🚀 Resultado esperado

    exemplo_fibonacci.py
    def calcula_fibonacci(n):
    if n <= 1:
        return n
    return calcula_fibonacci(n-1) + calcula_fibonacci(n-2)

print(calcula_fibonacci(10))

    Vantagens dessa Abordagem

    • O título deixa claro qual arquivo está sendo mostrado
    • Os números de linha facilitam referências ("veja a linha 3")
    • Leitores podem copiar o código com confiança

    🔖 Destacar Linhas Específicas¶

    Às vezes você quer chamar atenção para linhas específicas do código.

    Sintaxe:

    ```python hl_lines="2 3"
def processa_dados(lista):
    dados_processados = []   # Esta linha
    for item in lista:       # e esta também
        dados_processados.append(item * 2)
    return dados_processados
```

    🚀 Resultado esperado

    def processa_dados(lista):
    dados_processados = []   # Esta linha
    for item in lista:       # e esta também
        dados_processados.append(item * 2)
    return dados_processados

    🔍 Rastreamento de Mudanças: Mostrar Sugestões de Edição¶

    Quando você está documentando atualizações ou mudanças propostas, o Critic Markup permite mostrar exatamente o que foi alterado.

    🔖 Texto Deletado e Adicionado¶

    Sintaxe:

    Texto pode ser { -- deletado -- } e texto de substituição { ++ adicionado ++ }.

    🚀 Resultado esperado

    Texto pode ser deletado e texto de substituição adicionado.

    🔖 Operações Combinadas¶

    Sintaxe:

    Isso pode ser combinado em { ~~ uma ~> uma única ~~ } operação.

    🚀 Resultado esperado

    Isso pode ser combinado em umauma única operação.

    🔖 Destaque com Comentários¶

    Use essa técnica para adicionar comentários a seções específicas.

    Sintaxe:

    { ==Esta é uma seção importante== }{ >>Adicione isto ao resumo<< }

    🚀 Resultado esperado

    Esta é uma seção importanteAdicione isto ao resumo

    Caso de Uso

    Use rastreamento de mudanças quando:

    • Você está documentando um changelog
    • Mostrando comparações entre versões
    • Sugerindo edições ou melhorias
    • Colaborando em documentação

    🎭 Admonitions: Caixas de Atenção com Impacto Visual¶

    Admonitions (também chamadas de call-outs) são caixas destacadas que interrompem o fluxo do texto para chamar atenção a informações críticas.

    🔖 Sintaxe Básica¶

    Toda admonition começa com !!! seguida do tipo:

    Sintaxe:

    !!! note
    Este é um bloco de nota. Use para informações gerais.

!!! warning
    Este é um aviso. Use para questões importantes.

!!! tip
    Esta é uma dica. Use para sugestões úteis.

    🚀 Resultado esperado

    Note

    Este é um bloco de nota. Use para informações gerais.

    Warning

    Este é um aviso. Use para questões importantes.

    Tip

    Esta é uma dica. Use para sugestões úteis.

    🔖 Todos os Tipos Disponíveis¶

    Material for Mkdocs oferece uma variedade de tipos para diferentes situações:

    Tipo Cor Quando Usar
    note Azul Informações gerais complementares
    abstract Azul claro Resumos e visões gerais
    info Ciano Informações úteis
    tip Verde Dicas e boas práticas
    success Verde Operações bem-sucedidas
    question Verde claro FAQs e perguntas
    warning Laranja Alertas importantes
    failure Vermelho Falhas e erros
    danger Vermelho escuro Avisos críticos
    bug Rosa Relatos de bugs
    example Roxo Exemplos práticos
    quote Cinza Citações

    🔖 Admonitions com Título Personalizado¶

    Por padrão, o título é o tipo. Mas você pode customizar:

    Sintaxe:

    !!! warning "⚠️ Cuidado com Segurança"
    Nunca coloque suas credenciais no repositório público.

    🚀 Resultado esperado

    Cuidado com Segurança

    Nunca coloque suas credenciais no repositório público.

    🔖 Admonitions Colapsáveis¶

    Quando a informação é longa, torne-a colapsável:

    Sintaxe:

    ??? tip "Clique para expandir"
    Este é um bloco colapsável. O usuário precisa clicar para ver o conteúdo.

    Você pode colocar vários parágrafos aqui.

    🚀 Resultado esperado

    Clique para expandir

    Este é um bloco colapsável. O usuário precisa clicar para ver o conteúdo.

    Você pode colocar vários parágrafos aqui.

    🔖 Admonitions Aninhadas¶

    Sim, você pode colocar uma admonition dentro de outra!

    Sintaxe:

    !!! danger "Erro Crítico"
    Seu banco de dados estava corrompido.

    !!! info "Recuperação"
        Usamos um backup automático de 1 hora atrás.

    🚀 Resultado esperado

    Erro Crítico

    Seu banco de dados estava corrompido.

    Recuperação

    Usamos um backup automático de 1 hora atrás.

    📊 Combinando Técnicas: Um Exemplo Completo e Prático¶

    Agora que você conhece todos os recursos, vamos combiná-los em um exemplo real — documentando uma API.

        ---
    title: API de Autenticação
    description: Documentação completa da autenticação
    ---

    # 🔐 API de Autenticação

    ## Visão Geral

    Esta API permite que você ==autentique usuários== de forma segura usando tokens JWT.

    !!! abstract "Resumo Rápido"
        - Suporta autenticação básica e OAuth 2.0
        - Tokens expiram em **24 horas**
        - Taxa limite: 100 requisições por minuto

    ## Instalação

    ```bash
    pip install requests-auth
    ```

    ## Exemplo Básico

    ```python title="auth_example.py" linenums="1"
    import requests_auth

    auth = requests_auth.BasicAuth('usuario', 'senha')
    response = requests.get('https://api.exemplo.com/user', auth=auth)
    ```

    ## Atalhos Importantes

    | Atalho | Função |
    |--------|--------|
    | ++alt+a++ | Abre o painel de autenticação |
    | ++ctrl+shift+t++ | Teste a conexão |

    !!! warning "Segurança"
        ~~Nunca~~ **Nunca** armazene senhas em variáveis de ambiente de produção.

    !!! tip "Melhor Prática"
        Use ==gerenciadores de segredos== como **AWS Secrets Manager** ou **Vault**.

    !!! question "O que é JWT?"
        JWT (JSON Web Token) é um padrão aberto para transmissão segura de informações.

    ⚙️ Checklist de Configuração Completa¶

    Para aproveitar todos esses recursos ao máximo, certifique-se de que seu mkdocs.yml contenha:

    theme:
  name: material

markdown_extensions:
  # Básico
  - markdown.extensions.tables
  - markdown.extensions.toc

  # Formatação Avançada
  - pymdownx.critic
  - pymdownx.caret
  - pymdownx.keys
  - pymdownx.mark
  - pymdownx.tilde

  # Código Destacado
  - pymdownx.highlight:
      use_pygments: true
  - pymdownx.superfences

  # Listas e Admonições
  - pymdownx.tasklist
  - admonition

  # Metadados
  - meta

    Pronto para Começar

    Com essa configuração, você tem 100% dos recursos apresentados neste artigo funcionando perfeitamente em sua documentação.

    🎯 Melhores Práticas de Formatação¶

    ✅ O Que Fazer¶

    • ✓ Use negrito para conceitos-chave apenas — não exagere
    • ✓ Combine formatação com admonitions para máximo impacto
    • ✓ Use destaque apenas para as coisas mais importantes
    • ✓ Numere linhas de código quando há muitas linhas
    • ✓ Sempre fornece título quando mostra um arquivo de código

    ❌ O Que Evitar¶

    • ✗ Não use muito negrito itálico — fica cansativo
    • ✗ Não use tachado constantemente
    • ✗ Não coloque admonitions dentro de admonitions profundamente aninhadas
    • ✗ Não destaque mais de 30% de qualquer parágrafo
    • ✗ Não misture muitos estilos diferentes no mesmo parágrafo

    Regra de Ouro

    • Se tudo está destacado, nada está destacado.
    • Mantenha a simplicidade.
    • A formatação deve guiar o leitor, não distraí-lo.
