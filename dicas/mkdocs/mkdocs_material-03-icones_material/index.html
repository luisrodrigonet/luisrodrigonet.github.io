    🤖 Ícones Material no Material for MkDocs¶

    O Material for MkDocs inclui suporte nativo para Ícones Material Design, permitindo adicionar ícones vetoriais consistentes e profissionais em toda a documentação.

    1️⃣ Configuração Básica¶

    🎮 Habilitar Suporte a Ícones

    markdown_extensions:
  - pymdownx.emoji:
      emoji_index: !!python/name:material.extensions.emoji.twemoji
      emoji_generator: !!python/name:material.extensions.emoji.to_svg

    🎮 Configuração Recomendada

    site_name: Meu Site
theme:
  name: material
  features:
    - content.code.copy
    - navigation.tabs
    - navigation.sections

markdown_extensions:
  - pymdownx.emoji:
      emoji_index: !!python/name:materialx.emoji.twemoji
      emoji_generator: !!python/name:materialx.emoji.to_svg
  - pymdownx.superfences
  - admonition
  - pymdownx.details

extra:
  generator: false

    🌃 Features¶

    As configurações, além dos ícones, permitem ativar funcionalidades extras:

    Configuração Explicação Exemplo Prático
    content.code.copy Adiciona um botão de "copiar" no canto superior direito de todos os blocos de código (```). Facilita a vida do usuário para copiar comandos de instalação ou trechos de código sem ter que selecionar o texto manualmente.
    navigation.tabs Transforma a navegação principal (de nível superior) em abas no topo da página, em vez de uma longa lista na barra lateral. Se você tem seções como "Início", "API" e "Tutoriais", elas aparecerão como abas clicáveis no header. Observação: Requer uma estrutura de navegação específica no seu mkdocs.yml (e.g., agrupando páginas sob um título).
    navigation.sections Agrupa páginas que estão na mesma seção na barra lateral, permitindo que a seção seja recolhida (collapsed). Se você tem "Introdução" e depois "Capítulo 1", "Capítulo 2", etc., todos esses capítulos estarão aninhados sob a seção "Introdução" e podem ser escondidos para economizar espaço na barra lateral.

    Observação Adicional sobre features

    A ativação dessas funcionalidades é crucial para aproveitar o que o tema Material oferece, proporcionando uma experiência de usuário moderna e otimizada.

    🏙️ Markdown Extensions¶

    As extensões de Markdown são ferramentas que adicionam novas sintaxes ou funcionalidades à forma como o MkDocs processa seus arquivos .md. A configuração apresentada anteriormente habilita as seguintes extensões:

    Configuração Explicação Exemplo Prático
    pymdownx.emoji: ... Uma extensão poderosa para renderizar emojis de forma consistente (neste caso, usando o conjunto Twemoji). Você pode digitar :rocket: e ele será transformado no ícone do foguete (🚀). O código subsequente (emoji_index e emoji_generator) garante que o emoji seja renderizado como SVG (Scalable Vector Graphics), garantindo alta qualidade e performance.
    pymdownx.superfences Melhora a forma como o Markdown lida com blocos de código, permitindo o aninhamento de outros elementos (como admonition) dentro deles e melhorando o destaque de sintaxe. É fundamental para garantir que blocos de código complexos (como aqueles dentro de abas ou outros elementos) sejam renderizados corretamente.
    admonition Permite criar caixas de destaque (notas, avisos, alertas, dicas) com cores e ícones diferentes. Para criar um bloco de "Atenção": !!! warning "Atenção" Este é um aviso importante.
    pymdownx.details Permite a criação de blocos "detalhes" que podem ser expandidos e recolhidos (como um accordion). Útil para esconder informações detalhadas que não precisam ser vistas imediatamente: <details><summary>Clique para ver mais</summary>Conteúdo escondido.</details>

    Observação Adicional sobre Extensões

    O prefixo pymdownx. indica que estas são extensões avançadas que fazem parte da biblioteca PyMdown Extensions, amplamente utilizada com o tema Material. Elas transformam o Markdown básico em uma ferramenta de escrita muito mais poderosa e rica.

    🌁 Extra¶

    Esta seção é usada para definir variáveis ou configurações que não se encaixam nas outras categorias.

    Configuração Explicação
    generator: false Uma configuração do Material for MkDocs que remove a pequena nota "Desenvolvido com MkDocs" que geralmente aparece no rodapé.
    Exemplo Prático: Seus usuários não verão a nota "Desenvolvido com MkDocs usando o tema Material" no rodapé do site, dando-lhe uma aparência mais "limpa" ou customizada.

    2️⃣ Os Ícones¶

    Esta seção descreve como podemos trabalhar com ícones em documentos no MkDocs.

    🎮 Sintaxe Fundamental

    :material-icon-name:

    Material Design Icons (também conhecida como Material Icons) são organizadas por tema e função, a seguir temos uma lista das suas principais categorias:

    1. Action (Ação): representam ações que o usuário pode realizar, como delete, favorite, share, save, lock.
    2. Alert (Alerta): notificações, avisos e status importantes, como error, warning, notifications, info.
    3. Av (Audio & Video): controle de mídia, como play_arrow, pause, volume_up, skip_next.
    4. Communication (Comunicação): mensagens, chamadas e contato, como message, call, email, chat.
    5. Content (Conteúdo): manipulação de conteúdo, como add, create, copy, save, archive.
    6. Device (Dispositivo): hardware ou funções do dispositivo, como bluetooth, wifi, battery, screen_rotation.
    7. Editor (Editor): funcionalidades de edição de texto e documentos, como format_bold, attach_file, insert_chart, table_chart.
    8. File (Arquivo): arquivos, pastas e o sistema de arquivos, como folder, cloud_upload, request_quote.
    9. Hardware (Hardware): periféricos e componentes de hardware, como keyboard, mouse, headphones, smartphone.
    10. Home (Casa): dispositivos e conceitos de casa inteligente, como lightbulb, thermostat, security_camera.
    11. Image (Imagem): edição e visualização de imagens, como photo_camera, edit, palette, filter_vintage.
    12. Maps (Mapas): localização, navegação e lugares, como place, navigation, local_restaurant, directions_car.
    13. Maps (Navigation - Navegação de UI): (Nota: Esta categoria está listada como "Maps" na biblioteca, mas contém ícones de navegação de UI). Ícones para navegar em um aplicativo, como menu, arrow_back, home, expand_more.
    14. Navigation (Navegação): Ícones para wayfinding e rotas, como explore, near_me, layers.
    15. Notification (Notificação): alertas do sistema e feedback, como notifications_active, event_available, priority_high.
    16. Places (Lugares): Ícones para diversos locais e serviços, como local_cafe, business_center, hotel, beach_access.
    17. Social (Social): redes sociais e interações pessoais, como person, group, share, thumb_up.
    18. Toggle (Alternância): botões de seleção e estado, como check_box, radio_button_checked, toggle_on.

      • Clique no ícone escolhido
